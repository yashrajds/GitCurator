GitCurator

Autonomous AI-powered GitHub profile manager and repository curator that keeps your developer presence modern, fresh, and impactful without manual toil.

⭐ View on GitHub 🚀 Quick Commands
✨

Profile README Auto-Updater

Gathers pinned repos, top languages, and recent commit events to synthesize a modern developer portfolio README with shields badges and live stats.

gitcurator update-readme
🧹

Repo Hygiene & Cleanup

Scans for stale repositories (>6mo inactive), empty repos, and unmaintained forks. Flags missing READMEs, descriptions, or licenses with dry-run safety.

gitcurator audit / cleanup
🏷️

AI Metadata & Topics

Analyzes repository code to generate punchy descriptions (under 140 chars) and discoverability topics/tags, suggesting cleaner repo names when ambiguous.

gitcurator update-metadata
📦

Changelogs & SemVer

Inspects commit messages since the last release to recommend SemVer bumps (major/minor/patch) and draft Keep-a-Changelog release notes automatically.

gitcurator changelog <repo>
🛡️

Safety & Dry-Run by Default

Every mutation supports --dry-run and requires confirmation before destructive actions. Full audit trail recorded in activity_log.json.

gitcurator logs
⏱️

Scheduled Automation

Ready-to-deploy GitHub Actions cron workflow to keep your profile updated automatically on a weekly or daily schedule without local intervention.

.github/workflows
bash — gitcurator CLI

# Install GitCurator locally

$ pip install -r requirements.txt && pip install -e .


# 1. Audit all your GitHub repositories

$ gitcurator audit --threshold-months 6


# 2. Preview generated profile README with Gemini AI

$ gitcurator update-readme --dry-run


# 3. Enhance repository metadata & discoverability tags

$ gitcurator update-metadata <repo-name> --dry-run


# 4. Generate Changelog & SemVer release notes

$ gitcurator changelog <repo-name> --create-release
